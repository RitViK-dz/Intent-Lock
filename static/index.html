💡 How IntentLock Protects Users

  1. Intent Proposal: The agent requests human approval before high-stakes financial operations.
  2. Human Authorization: The human verifies the item, price, and payee. Approving mints a single-use Ed25519 digital signature.
  3. Cryptographic Binding: The token tightly couples the exact authorized item, maximum amount, payee, and single-use nonce.
  4. Store Verification: The store verifier rejects any request where an attacker manipulated the payee or amount, even if the agent is fully compromised.
