🔍 The 6 Verification Rules

  • Signature Validity: Verifies signature using issuer public key (no private keys in store).
  • Expiration (TTL): Rejects tokens older than their lifespan.
  • Store Binding: Ensures token is bound to demo-store.
  • Agent Identity: Confirms agent ID matches token subject.
  • Payee & Item Match: Payee must match token (blocks recipient swap attacks). Item must match (blocks item substitution).
  • Atomic Replay Guard: Nonce is atomically inserted into database; duplicate attempts are blocked instantly.
